# Picture Cleaner for Mac (Apple Silicon)

Android판의 세 단계를 macOS 데스크톱 앱으로 옮긴 버전입니다.

## 실행

1. `Picture Cleaner.app`을 Applications 폴더로 옮깁니다.
2. 최초 실행 때 macOS가 개발자를 확인할 수 없다고 표시하면 앱을 Control-클릭하고 **열기**를 선택합니다.
3. 네이버 블로그 자동화에서 블로그 아이디를 입력하고 **네이버 로그인/블로그 열기**를 눌러 로그인합니다.
4. 댓글 자동 답글은 최근 10일 게시글만 확인하며, 내 답글이 화면에 있거나 로컬 처리 기록에 있는 댓글은 건너뜁니다.
5. 최근 10일 글의 공감 상태를 확인해 아직 공감하지 않은 글만 처리할 수 있습니다.
6. 이웃 새글 댓글은 최소 15초 이상의 사용자 지정 간격과 다양한 무작위 문구를 사용하며, 이미 내 댓글이 있는 글은 건너뜁니다.
7. 시작 즉시 다음·구글·크리에이터 어드바이저·네이버 시그널에서 각 10개를 수집해
   왼쪽에 표시합니다. 한 항목을 선택하면 오른쪽에 중복 제거된 연관 검색어만 표시·복사됩니다.
8. 상단에 직접 키워드를 입력하고 Enter를 누를 수 있습니다. 여러 단어이면 전체 문구 결과와
   첫 단어 추가 결과를 오른쪽 상·하단에 분리하고 상단과 중복되는 첫 단어 결과를 제거합니다.
9. 3·4번 네이버 작업은 설치된 네이버 웨일을 전용 프로필로 실행하며, 이웃 새글은 한 번에
   최대 200개까지 설정할 수 있습니다.

네이버의 보안 확인 또는 CAPTCHA는 자동으로 우회하지 않습니다. 전용 네이버 창에서 직접 확인을 마친 뒤 다시 실행하세요.

## 개발 빌드

```bash
npm ci
npm run build:mac
```

결과물은 `dist/Picture-Cleaner-M1-1.3.0.zip`입니다.
