# Picture Cleaner for Mac (Apple Silicon)

Android판의 세 단계를 macOS 데스크톱 앱으로 옮긴 버전입니다.

## 실행

1. ZIP 파일의 압축을 완전히 풉니다.
2. `Install-Picture-Cleaner.command`를 Control-클릭하고 **열기**를 선택합니다.
3. 설치 도구가 ad-hoc 서명된 앱을 `~/Applications`에 복사하고 다운로드 격리 속성과
   코드 서명을 확인한 뒤 실행합니다. 이후에는 `Picture Cleaner.app`을 바로 실행합니다.
4. 네이버 블로그 자동화에서 블로그 아이디를 입력하고 **네이버 로그인/블로그 열기**를 눌러 로그인합니다.
5. 내 글 작업은 사용자가 정한 최근 일수와 답글 간격을 적용합니다. 댓글 하트와 무작위 감사 답글을 함께 처리하며, 이미 처리한 댓글은 건너뜁니다.
6. 이웃 새글 댓글은 최소 15초 이상의 사용자 지정 간격과 다양한 무작위 문구를 사용합니다.
   댓글 입력 영역을 먼저 활성화하고 등록 버튼과 입력창 초기화를 확인한 경우에만 완료로 기록하며,
   이미 내 댓글이 있거나 처리 기록이 있는 글은 건너뜁니다.
7. 시작 즉시 다음·구글·크리에이터 어드바이저·네이버 시그널에서 각 10개를 수집해
   왼쪽에 표시합니다. 한 항목을 선택하면 오른쪽에 중복 제거된 연관 검색어만 표시·복사됩니다.
   실시간 40개를 먼저 표시한 다음 크리에이터 어드바이저의 검색 유입 트렌드에서
   세계여행, 비즈니스·경제, IT·컴퓨터, 교육·학문, 자동차, 게임 분야를 각 20개씩 추가합니다.
   adsensefarm.kr의 다음·구글 응답이 없거나 부족하면 다음 홈페이지 실시간 트렌드와
   Google Trends 한국 급상승 RSS에서 자동으로 보충하고, 실제 사용된 보조 출처를 화면에 표시합니다.
8. 상단에 직접 키워드를 입력하고 Enter를 누를 수 있습니다. 여러 단어이면 전체 문구 결과와
   첫 단어 추가 결과를 오른쪽 상·하단에 분리하고 상단과 중복되는 첫 단어 결과를 제거합니다.
9. 3·4번 네이버 작업은 설치된 네이버 웨일을 전용 프로필로 실행하며, 전체이웃 새글 API를
   페이지별로 읽어 한 번에 최대 200개까지 처리할 수 있습니다.
10. 기존 네이버 웨일에 로그인되어 있으면 해당 로그인 세션을 자동화 프로필로 동기화해
    로그인 화면 없이 내 글 답글·하트 및 이웃 새글 댓글 작업을 시작합니다.
11. 상단 탭 번호는 1번 실시간 연관 검색어, 2번 Google 이미지 검색, 3번 네이버 블로그,
    4번 댓글·이웃 소통 순서입니다. 1번 오른쪽 연관어 하나를 고른 뒤 2번에서 실행하면
    한글을 영어로 번역해 웨일의 Google 이미지 검색 결과를 엽니다.
12. 2번에서는 Creative Commons 필터 결과의 원본 미리보기 주소를 우선 저장해 세로 사진과
    가장자리를 보존합니다. 원본을 받을 수 없을 때만 전체 이미지가 보이는 `contain` 캡처를 사용합니다.
13. 저장 이미지 15장은 원본 비율을 유지한 2단계 고품질 보간, 약한 대비·선명도 보정으로
    최대 2048px 기준 해상도를 개선하거나 캡처부터 순서대로 실행할 수 있습니다.

네이버의 보안 확인 또는 CAPTCHA는 자동으로 우회하지 않습니다. 전용 네이버 창에서 직접 확인을 마친 뒤 다시 실행하세요.

## 개발 빌드

```bash
npm ci
npm run build:mac
```

결과물은 `dist/Picture-Cleaner-M1-1.7.2.zip`입니다.
