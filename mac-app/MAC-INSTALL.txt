Blog M1 2.0.2 설치와 첫 실행

1. Blog-M1-2.0.2.zip 압축을 완전히 풉니다.
2. Install-Blog.command를 Control-클릭하고 '열기'를 선택합니다.
3. 원본 서명과 ARM64를 확인한 뒤 ~/Applications/Blog.app에 설치합니다.
   실행 중인 기존 Blog만 정상 종료를 기다린 뒤 교체합니다. 종료하지 못하면 설치를 중단합니다.
   기존 Blog.app은 휴지통의 Blog-previous 폴더에 백업하며 사용자 설정은 삭제하지 않습니다.
4. 앱의 'CLI 연결 확인'에서 본인 Mac에 설치한 Codex / Claude / Antigravity를 확인합니다.
   '로그인' 버튼은 Terminal을 엽니다. 본인 구독 계정으로 로그인한 뒤 다시 확인하세요.
   API 키는 사용하지 않습니다. Terminal 로그인을 마치지 않았는데 성공으로 표시하지 않습니다.
   ChatGPT의 브라우저 콜백 인증이 실패하면 '기기 코드 로그인'을 사용합니다.
   Terminal에 표시되는 주소와 코드로 본인 계정을 인증한 뒤 CLI 로그인을 재확인합니다.
5. 네이버 저장·발행에는 '웨일 네이버 로그인'을 눌러 새 전용 창에서 최초 한 번 로그인합니다.
   이후 이 전용 프로필을 그대로 유지합니다. 일반 웨일의 암호·쿠키 파일은 복사하지 않습니다.
6. 수동 작성: 키워드 입력 → 연관어·검색 의도 분석 → CLI 작성·검수·이미지 준비 → 선택한 완료 동작.
   완료 동작은 네이버 임시저장, 바로 발행, 로컬 저장 중 선택합니다. 기본은 네이버 임시저장입니다.
7. 자동화는 기본 꺼짐입니다. 켜면 바로 첫 회차를 시작하며 1~6시간 간격으로 반복합니다.
   끄면 현재 작업을 중지하고 저장된 회차를 유지합니다.
8. 프롬프트 옵션과 CLI 역할·모델은 자동 저장됩니다. 실행 도중 변경은 다음 새 글에 적용합니다.

인증 안내
- 이 패키지는 ARM64 ad-hoc 코드 서명 검증판이며 Apple Developer ID 공증판은 아닙니다.
  공증 인증서가 제공되지 않아 처음 설치 도구를 열 때 macOS 확인이 나타날 수 있습니다.
  설치 도구는 이 앱에만 적용하며 macOS 전체 보안 설정은 바꾸지 않습니다.
- 네이버 CAPTCHA·추가 인증 또는 CLI 구독 로그인이 나오면 본인 Mac에서 직접 완료해야 합니다.
- 코드 서명, 네이버 로그인, CLI 로그인은 서로 다른 상태이며 하나의 성공을 다른 인증으로 대신하지 않습니다.
- '실행 자료 폴더'의 logs, mac-active-run.json, blog-runs에서 오류와 저장 원고를 확인할 수 있습니다.
- 네이버 제출 후 결과가 불확실하면 자동 재발행하지 않고 영수증을 남깁니다.
