# Picture Cleaner PC

Android APK의 세 동작을 Windows 데스크톱 흐름으로 옮긴 버전입니다.

1. 이미지 자동 정리: 폴더의 사진을 자동 크롭하고 2048px까지 확대·선명화합니다.
2. 실시간 연관 검색어: 실행 직후 다음·구글·크리에이터 어드바이저·네이버 시그널에서
   각각 10개씩 총 40개를 수집합니다. 경기 결과·중계 등 일회성 항목을 제외하고 출처별로
   표시하며 한 개만 선택할 수 있습니다. 선택 즉시 하단에 연관어가 표시되고 제목 없이
   연관어 내용만 복사됩니다.
3. 네이버 블로그 자동화: OpenAI/Gemini로 초안을 만들고 네이버 글쓰기와 클립보드로 연결합니다.
4. 댓글·이웃 소통: 최근 10일 내 글의 미응답 댓글에 다양한 감사 답글을 남기고, 꺼진 댓글 공감을 누릅니다. 이웃 새글 댓글은 사용자가 정한 초 간격과 최대 개수를 적용합니다.

`dist/PictureCleanerPC.exe`를 실행하면 됩니다. 설치가 필요 없는 단일 실행 파일입니다.

- 결과 사진: 선택한 폴더 아래 `PictureCleaner`
- 설정/검색어 DB: `%LOCALAPPDATA%\PictureCleanerPC`
- API 키는 파일에 저장하지 않으며 프로그램을 다시 열 때 재입력합니다.
- 원본 삭제 옵션은 영구 삭제가 아니라 Windows 휴지통 이동입니다.
- 네이버 로그인과 최종 발행은 계정 보호 및 오발행 방지를 위해 브라우저에서 사용자가 확인합니다.
- 댓글 자동화는 별도 Chrome 프로필을 사용합니다. `네이버 로그인 창 열기`에서 최초 한 번 로그인하세요.
- `Phone 미래 전망 자동화`는 실시간 검색어 후보별 네이버·다음·구글 연관어 수를 비교해 주제를 고르고, 전체 키워드를 ChatGPT의 `Phone 미래 전망`에 입력합니다.
- 완성된 글은 네이버 제목·본문에 입력하고 오늘 캡처 사진을 최대 10개 첨부한 뒤 임시저장합니다. 발행 버튼은 선택하지 않습니다.
- 최초 사용 시 `ChatGPT 로그인 창`과 `네이버 로그인 창 열기`에서 각각 로그인해 주세요. 두 사이트는 같은 자동화 전용 Chrome 프로필을 재사용합니다.
- 답글·공감·이웃 댓글 기록은 `%LOCALAPPDATA%\PictureCleanerPC\naver_comment_history.json`에 저장되어 중복 실행을 방지합니다.
- 이웃 댓글 간격은 최소 10초이며 한 번에 최대 30개로 제한됩니다.
- 댓글·하트 및 이웃 새글 작업 버튼은 별도 확인 창 없이 즉시 실행됩니다.

다시 빌드하려면 PowerShell에서 `.\build.ps1`을 실행하세요.
