# Picture Cleaner PC · CLI 블로그 (2026-09-12)

사진 정리·실시간 검색어·네이버 글쓰기·댓글 도구를 포함한 Windows 프로그램입니다.
실행 파일: `dist/PictureCleanerPC-CLI-Blog-20260912.exe`
기존 프로그램을 닫고 새 파일을 실행하세요. 제목에 `CLI 블로그 2026-09-12`가 표시됩니다.

## CLI 글쓰기 사용법

1. **3 네이버 블로그 자동화**에서 **CLI 연결 확인**을 누릅니다. 로그인되지 않은 CLI는
   **CLI 로그인 안내**에서 해당 로그인 창을 엽니다. ChatGPT는 Codex CLI의 ChatGPT 계정 로그인,
   Claude는 Claude 계정 로그인, Antigravity는 자체 로그인 세션을 사용합니다.
   작업 시작 전에도 필수 CLI 설치·로그인을 확인하므로, 필요한 로그인이 없으면 생성 전에 알려줍니다.
2. 주제를 직접 입력하거나 **관심 주제 자동 선정**을 누릅니다. 연관 검색어는 1번 탭에서 확인합니다.
   직접 입력한 주제로 준비할 때도 연관 검색어를 새로 조회하고, 이전 주제의 검색어는 제외합니다.
   순위는 검색어의 질문 의도·출처 수·설명용 이미지 적합성을 반영한 예상 관심 점수이며 실측 CTR이 아닙니다.
3. 사용자가 제공한 4천자 이상 블로그 글쓰기 프롬프트가 기본으로 들어 있습니다. 내용을 자유롭게
   수정해 저장할 수 있습니다. **새 이름으로 저장**하면 여러 프롬프트를
   선택할 수 있습니다. 실행 단계는 1~4개이며 기본값은 ChatGPT → Claude → Antigravity → ChatGPT입니다.
   동일 CLI를 여러 번 선택할 수 있고, 순서·선택한 프롬프트·검수 방식·모델·발행 설정은 재실행해도 유지됩니다.
4. **글·이미지 준비**를 누릅니다. 질문에 답하는 제목과 정확히 8개 내용 구역을 작성하고 지정한 CLI 순서로
   사실·출처·한국어 문체를 검수합니다. 검수 방식은 단계별 교차 검수, 마지막 CLI 집중 검수,
   선택 CLI 모두 검수 중 고릅니다. 문장 사이 빈 줄과 소제목, 네이버 편집기의 굵은 글씨를 사용하고,
   출처와 URL은 공개 본문에 출력하지 않습니다. 검증용 출처와 검수 결과는 실행 자료 폴더에 남습니다.
5. 구역별 실사 스타일 이미지 후보를 Antigravity 4장, ChatGPT 4장 생성합니다. 실제 생성 도구의 성공과 새 파일을
   확인한 뒤 이미지 자체를 CLI에 전달해 글자·로고·워터마크·왜곡·관련성·품질·중복을 검사합니다.
   통과한 생성 이미지 6장을 선정합니다. 8장 생성이나 6장 선정이 실패하면 발행하지 않습니다.
   업로드용 JPEG 사본은 긴 변을 최소 2048픽셀로 보정하고 EXIF·XMP·생성 도구 등 메타데이터를 제거합니다.
   원본과 내부 생성·검수 기록은 유지합니다. 확대가 원본에 없는 세부 정보를 복구하지는 않습니다.
6. Google 옵션을 켜면 검색 결과의 첫 두 유효 미리보기에서 이미지 요소만 캡처해 해상도와 선명도를
   보정합니다. 원본 페이지의 재사용 조건과 시각 검수가 모두 확인된 경우에만 최대 2장을 추가합니다.
   현재 자동으로 확인하는 원본은 Wikimedia Commons의 파일별 CC0·공유영역 표시입니다.
   공개 출처를 표시하지 않는 글쓰기 설정에 맞춰 출처 표시 의무가 있는 후보는 제외합니다.
   화면에서 글자를 자르거나 크기를 키우는 것만으로 저작권 문제가 해결되지는 않습니다.
7. 준비된 글을 확인한 후 **준비된 글 네이버에 입력·실행**을 누릅니다. 완료 후 설정이 **자동 발행**이면
   웨일 글쓰기에서 제목·8문단·사진을 입력하고 사진의 문단 위치와 내용을 확인한 뒤 발행합니다.
   **임시저장까지만**이면 임시저장 버튼을 누르고 저장 완료 표시를 확인합니다.
   **편집기에 입력만**이면 편집기에 배치하고 종료합니다. 입력만은 임시저장이나 발행을 뜻하지 않습니다.

상단 **반복 자동화 시작**은 주제 선정부터 지정한 완료 동작까지 반복합니다. 기본 완료 동작은
사용자 요청에 맞춰 **자동 발행**입니다. 간격은 1시간 또는 2시간이며, 시작 시 첫 회차를 실행한 뒤
시작 시각을 기준으로 반복합니다. 이전 회차가 길어지면 놓친 시각은 건너뛰고 작업을 겹쳐 실행하지 않습니다.
프로그램 시작만으로 자동 실행되지는 않습니다. **중지**는 현재 CLI 요청과 이후 단계를 중단합니다.
이미 제출한 발행 요청은 취소할 수 없습니다.

발행을 확인한 키워드는 실시간 후보와 저장된 키워드에서 제거하고, 다음 회차에는 다른 키워드를 사용합니다.
이력은 재실행해도 유지됩니다. 임시저장·입력만·실패는 발행 완료로 처리하지 않으며,
제출 결과가 불확실한 키워드는 확인 전까지 자동 선정에서 보류합니다.

## 저장 위치와 검증

- 설정·프롬프트: `%LOCALAPPDATA%/PictureCleanerPC/settings.json`
- 원고·이미지·검수 기록: `%LOCALAPPDATA%/PictureCleanerPC/blog-runs/`
- CLI 기능 상태: `%LOCALAPPDATA%/PictureCleanerPC/blog-cli-capabilities.json`
- 발행 결과·미확인 제출 기록: `%LOCALAPPDATA%/PictureCleanerPC/publication_receipts/`
- 발행 완료·선정 보류 키워드: `%LOCALAPPDATA%/PictureCleanerPC/published-topic-history.json`
- 댓글·공감 이력: `%LOCALAPPDATA%/PictureCleanerPC/naver_comment_history.json`

AI API 클라이언트와 API 키 입력창을 제거했습니다. 로그인된 CLI 자식 프로세스만 사용하며,
AI API 키 환경변수도 해당 자식 프로세스에 전달하지 않습니다. CLI 계정의 이용 한도는 적용됩니다.
기존 검색어 수집과 RSS 등 공개 웹 데이터 조회는 계속 사용합니다.
Antigravity 출처 검증은 요청별 임시 프로젝트에서 필요한 공개 도메인 읽기만 허용하며,
전역 설정과 기존 프로젝트는 변경하지 않습니다.

발행 성공은 네이버 게시물 URL과 표시된 제목을 확인한 경우에만 기록합니다. 발행 응답이 불확실하면
재실행해도 동일 원고를 자동 재제출하지 않습니다. 기록의 안내와 웨일 화면에서 상태를 확인하세요.
사진이 검수 후 변경되거나 문단/검수 기록이 달라진 경우에도 발행을 중단합니다.

브라우저 버전에 맞춰 실행 시 확인됩니다. 결과 사진은 원본을 보존하며, 원본 삭제 옵션은 휴지통 이동입니다.
