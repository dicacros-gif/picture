# Blog 자동화 전체 재점검과 개선

작성일: 2026-09-13. 사용자의 추가 인터뷰 없이 기존 요구와 실제 코드·실행 결과를 기준으로 우선순위를 정했다.

## 수정 기준

자동화를 오래 켜 두거나 중지·재시작해도 같은 작업의 상태가 이어져야 한다. 같은 글·댓글을 중복 제출하지 않고, 승인한 사진을 불필요하게 다시 만들지 않는다. 실패 원인은 숨기지 않고 다음 복구 단계가 실제로 그 원인을 해결하도록 한다.

원고는 기본 문체와 전체 4,000자·8개 구역을 유지한다. 사용자 프롬프트는 추가 지침으로 적용한다. 팩트 보강은 확인된 정보 추가에 한정하고 마지막 문체 수정은 사실과 금액·날짜·단위를 유지한다. LLM 처리는 구독 계정 CLI로 수행한다.

## 복구 상태의 의미

- **준비 중:** 같은 주제와 시작 시점의 설정으로 이어간다. 중지나 로그인 오류도 실행 폴더를 잃지 않는다.
- **원고 수정 필요:** 최종 검수 지적을 제한된 길이의 피드백으로 전달한다. `approved`만 보지 않고 사실·출처·검색 의도·문체 승인과 남은 문제를 함께 판정한다.
- **준비 완료:** 승인된 원고·사진을 사용한다. 설정 변경은 다음 새 글에 적용한다.
- **제출 불확실:** 같은 글·댓글을 자동 재등록하지 않는다. 제출 기록을 보존한다.
- **게시 완료:** 확인된 URL과 이력을 먼저 저장한다. 공개된 본문·사진 확인이 끝나지 않으면 자료를 남긴다.
- **회차 완료:** 네이버 작업을 반복하지 않고 남은 로컬 이력 저장만 마무리한다.

## 검증 방법

단위 테스트뿐 아니라 중지→재개, 인증 실패→재개, 브라우저 저장 성공→이력 저장 실패→재개, 키워드 수집→발행 소비의 경합을 연결해 검사한다. 사진 파일 변환과 최종 발행 자료 검사는 실제 파일을 사용한다. 외부 서비스를 대체한 시험과 실제 CLI·브라우저 확인 결과는 구분해서 기록한다.

실제 사용자 설정과 기존 웨일 작성 창을 건드리지 않도록 계정 진단 자료와 구글 검색 검증에는 별도 데이터 폴더·브라우저 프로필을 사용한다. 최종 실행 파일은 전체 테스트 후 빌드하고 기존 배포 파일과 해시를 대조한다.

## 실행 검증 기록

- ChatGPT CLI: 실제 구독 계정으로 짧은 영어 사진 검색어 JSON 생성 성공.
- Antigravity CLI: 실제 계정 요청에서 짧은 영어 사진 검색어 JSON 생성 성공.
- Claude CLI: 설치는 확인했으며 로그인은 필요하다. 현재 저장된 실행 순서에는 포함되어 있지 않다.
- 구글 검색: 별도 웨일 프로필에서 영어 검색 화면을 열어 기존 선택자가 추천 아이콘만 선택하는 현상을 재현했다. 실제 사진은 클래스 이름 없이 `data-img-wrapper`·`data-preview-id` 아래에 있었다.

- 구글 검색 → 원문 → 캡처: 실제 영어 검색에서 Commons의 Apollo 17 지구 사진 1장을 확보했다. 동일 원본 파일 연결과 원문에 표시된 Public domain, 링크·저작자 표시 의무 없음 템플릿을 확인했다. 검색 결과의 라이선스 필터만으로 승인하지 않는다. 현재 구글 미리보기의 DOM 갱신과 라이선스 주소의 `/deed.en` 형태도 처리한다.
- 구글 원본 → 설명 추가 → 최종 시각 검수: 실제 ChatGPT CLI 요청 2회, 16.08초. 원본의 글자·로고·워터마크·화질 검수를 통과한 후, 별도 상단 띠에 `우주에서 본 지구`를 넣었다. 최종 CLI도 설명의 정확성·가독성을 승인했다. 코드가 검수 승인값을 임의로 생성하거나 바꾸지 않았다. 원문 라이선스 증거가 업로드 사본과 발행 검증까지 유지되는 것도 확인했다.
- 실제 원고 작성: ChatGPT CLI로 노트북 배터리 주제의 초고를 생성했다. 137.48초, 8구역·6,273자였으며 원고 기본 검사를 통과했다.
- 실제 자동 편집: 소제목 연관어 1건, 연결 문장 2건, 어미 반복 1건을 부분 수정한 뒤 별도 최종 CLI 검수를 수행했다. 요청 2회, 58.07초. 재검사 지적 0건, 8구역·6,286자. 최종 CLI의 사실·출처·의도·문체 검수 응답도 승인됐고, 해당 응답은 수정 원고의 해시에 연결했다. 이는 해당 시험 원고에 대한 결과이며 모든 주제의 사실성을 보증하는 지표는 아니다.
- 전체 자동 테스트: `python -m unittest discover -p 'test_*.py' -q` — **466개 통과**, 62.435초. Tk 테스트 창을 닫은 뒤 남은 타이머 관련 출력은 있었으나 실패는 없었다.
- 댓글 브라우저 시험: 로컬 HTML에 실제 브라우저를 연결한 11개 시나리오 통과. 외부 네이버 댓글은 제출하지 않았다.
- `git diff --check`: 공백 오류 없음.
- 실제 창의 아이콘과 번들 수정 후 관련 UI·설정 테스트 44개를 다시 실행했고 모두 통과했다.

실제 요청 기록은 `qa-process-20260913/article-smoke/`, `article-smoke/editorial-smoke/`, `isolated-google/captures/`, `google-vision-smoke/`에 보존했다. 이번 점검에서는 실제 네이버 글·댓글 발행과 8장 전체의 새 이미지 생성을 수행하지 않았다. 글 입력·발행 영수증·중복 방지 경로는 자동 테스트와 로컬 브라우저 시험으로 확인했다.

## 배포

전체 테스트가 통과한 코드로 `build.ps1 -DistPath dist-update` 빌드를 완료했다. 실행 중인 Blog 프로세스가 없음을 확인하고 `dist-update/Blog.exe`를 기본 실행 경로 `dist/Blog.exe`에 반영했다. 기존 사용자 설정은 배포 과정에서 변경하지 않았다.

- 파일 크기: 60,147,756바이트.
- 두 실행 파일의 SHA-256: `A618A521C54CDD734DD897FA41560CCC6185E950D3BBD311B040964972D247D0`.
- 번들 검사: 기본 글쓰기 프롬프트와 녹색 B 아이콘 포함. 변경된 원고·설정·발행·진행 창 모듈 11개 누락 없음.
- 실제 사용자 설정의 자동 시작·자동 발행이 켜져 있으므로 배포 확인을 위해 실행 파일을 무작정 시작하지 않았다. 실행 파일 패키지 검사와 별도 데이터 폴더의 실제 CLI·브라우저 검증을 사용했다.
